## Introduction

LaraGram API Server: A Telegram Bot API server built on LaraGram MTProto.

## Official Documentation

Documentation for LaraGram API Server can be found on the [LaraGram website](https://laraxgram.github.io/v4/apiserver).

## Contributing

In order to ensure that the LaraGram community is welcoming to all, please review and abide by the [Code of Conduct](https://laraxgram.github.io/contributions.html#code-of-conduct).
